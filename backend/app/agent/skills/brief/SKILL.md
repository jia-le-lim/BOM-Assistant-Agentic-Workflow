# Workspace brief

Use the selected workspace's `batch_summary` and `top_exposure` results.
Lead with the workspace name and whether it has been scored.
Report scored items, counts by workflow status, pending USD exposure, and up to
five items still awaiting review. Distinguish review work from senior approval.
Finish with a practical next step supported by these records.

An empty queue is a valid result. Do not infer completion from a limited list;
use the whole-workspace status counts. Pending exposure is inventory value,
not realized savings or a forecast loss. A draft workspace needs a datasheet
and scoring before it has recommendations. Do not execute or stage changes.
