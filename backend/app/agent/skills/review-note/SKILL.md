# Draft a review note

Read the item's current values, stored recommendation, and procurement context
in the selected workspace. Existing item notes carry forward across review
cycles; identify them as historical context.

Return a copyable draft with: item and workspace; current and proposed levels;
stored reason and relevant procurement facts; unresolved questions; decision
pending reviewer input. Existing notes may support context but are not evidence
that a new approval occurred. Do not write in the reviewer's voice as though
they already accepted or rejected the recommendation. Mark the text as a draft.
Do not save it, stage a proposal, or infer replacement stocking quantities.
