# Check dormant-rule coverage

Use `get_dormant_coverage` in the selected workspace under the existing review
role requirement. Report total dormant rows, matched and uncovered counts,
coverage percentage, engine book value, rule-based book value, and the delta.

Call the delta an inventory book-value comparison, not a realized saving.
Explain that confirmed rules take effect on the next engine run; the current
scored batch retains the quantities originally shown to its reviewer. Do not
claim uncovered items have been individually inspected or modify any rule.
